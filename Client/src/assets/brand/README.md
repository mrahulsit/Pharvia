# Pharvia brand kit

Generated with ChatGPT (image generation) in Nov 2026, then cut out and exported locally.

| File | Size | Use |
|---|---|---|
| `pharvia-logo-source.png` | 1952×806 | **Original** from ChatGPT (lockup + app tile on white). Re-export everything from this file. |
| `pharvia-mark.webp` | 229×256, transparent | The icon: a P with a forward arrow (via, the way) and a medical plus. Used in the header, footer, auth modal, PLUS card and loader. Works on white, green, teal and dark backgrounds. |
| `pharvia-mark.png` | 351×392, transparent | Same icon at full resolution (for docs and slides). |
| `pharvia-lockup.webp` | 1000×315, transparent | Icon + "Pharvia" + "at every step". **Light backgrounds only**, because the wordmark is dark green. |

Favicons and app icons live in `Client/public/` and are linked from `index.html`:
`favicon.ico` (16/32/48), `favicon-16x16.png`, `favicon-32x32.png`, `apple-touch-icon.png` (180, white),
`android-chrome-192x192.png`, `android-chrome-512x512.png`, `maskable-512x512.png` (mark inside the 80% safe
zone), `og-image.png` (1200×630 social preview) and `site.webmanifest`.

Colours: bright green `#1CB04B`, deep green `#0A5A25` (also the `theme-color`).

Notes:
- These are raster images from an AI generator, not vector files. Before print or large-format use, have the
  mark traced into an SVG (it's simple geometry: rounded rectangles, an arrow and a plus).
- For commercial use, check that the mark and name don't conflict with existing trademarks (IP India classes 5,
  35 and 44).
